# 常见问题排查

排查前先确认部署方式、应用版本、数据库版本、错误时间和是否经过反向代理。提交反馈时只提供脱敏日志摘要，不要发送报告原件、OCR 正文、检查结果、成员信息或密钥。

## 登录和访问

**fnOS 访问 403 或来源不一致**：确认通过 fnOS 应用入口访问，应用没有被单独映射成 Docker 本地账号服务。停止并重新启动应用，让网关重新注入会话环境。

**Docker 反向代理登录失败**：确认代理传递 Host 和 `X-Forwarded-Proto`，HTTPS 场景设置 `TRUST_PROXY=1`，浏览器允许 Cookie。不要在未使用可信代理时启用该配置。

## NAS 导入

**fnOS 看不到已授权目录**：确认应用中心已授权正确目录，并停止后重新启动应用。fnOS 目录授权由系统注入，应用设置变更不会替代重启。

**Docker 看不到报告**：确认 `REPORTS_HOST_PATH` 指向 Docker 主机上的真实目录，目录以只读方式挂载到 `/reports`，然后执行：

```bash
docker compose up -d --force-recreate
docker compose exec health-records sh -c 'ls -la /reports | head'
```

容器用户 UID 1000 必须能够读取并遍历源目录；应用只显示支持的图片和 PDF 文件。

## 上传、下载和备份

**上传返回 413 或 500**：检查反向代理的请求体大小、临时目录空间、读取超时和应用日志。大文件不应经过过小的网关缓冲限制。

**备份下载很慢、失败或浏览器无响应**：确认代理允许流式响应、Range 请求和长读取超时，并关闭不适合大文件的响应缓冲。优先使用应用内生成完成后再下载。

**恢复上传失败**：检查代理请求体上限、临时目录空间、数据目录写权限和备份 SHA-256 校验。Docker 数据目录必须由 UID 1000 读写。

## OCR 和 AI

**OCR 安装失败**：在“我的 -> 运行与识别”查看 Python、后端、模型和安装日志。常见原因是 Python/venv/pip 不可用、无法访问 Python 包源、架构没有对应 wheel、磁盘空间不足或数据目录不可写。

**PDF 清晰但指标缺失**：部分 PDF 只有不完整的文字层。应用会按页补充高清 OCR；可在报告处理详细日志中确认页面是否执行文字层与 OCR 合并，之后重试 OCR+AI。

**MinerU 提示认证失败**：只有精准解析使用 Token。由管理员在“我的 -> 运行与识别”重新保存有效 Token，再手动重试失败任务。不要把 Token、Authorization 头、签名上传地址或任务结果正文复制到反馈日志。

**MinerU 提示请求受限、网络错误或超时**：确认设备/容器可以通过 HTTPS 访问 `mineru.net` 及 MinerU 返回的官方签名存储域名，并稍后重试。429、网络、30 分钟超时、服务异常和结果损坏不会静默切换到本地 OCR；只有源文件超过 Agent 10 MB/20 页、精准解析 200 MB/200 页，或上游明确返回相同文档限额时才会自动使用本地 OCR。处理详情会显示请求方式、实际引擎和限额降级事件。

**MinerU 文字可以校对但原图没有高亮**：MinerU Markdown 没有应用可用的行坐标。文字校对、全文搜索、AI 整理和证据引用仍然可用，应用不会为原图文字叠加伪造位置。

**Ollama 无法连接**：Docker 不要填写 `127.0.0.1`，应使用 `host.docker.internal` 或 Ollama 所在机器的局域网 IP。确认 Ollama 监听地址、防火墙和模型名称正确。

## 指标和趋势

**指标没有进入趋势**：先在报告详情确认原始名称、结果、单位和 OCR 证据是否完整。百分比/绝对值、不同标本、不同方法和不同侧别不会强行合并；未命中名称会进入管理员问题池。维护远程字典后，需要执行历史指标字典匹配。

**趋势名称与报告名称不同**：这是标准化指标名称与原始报告名称的区别。点击趋势点可以回到来源报告和原件；若关联错误，应检查单位、侧别、检测方法和 OCR 证据，不要只按名称相似判断。

## 仍无法解决时

请提供部署方式、应用版本、数据库版本、问题发生时间、脱敏错误摘要、是否经过反向代理，以及相关页面显示的任务状态。不要提供完整日志、备份文件或包含健康数据的截图。
