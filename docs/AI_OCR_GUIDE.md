# OCR 与 AI 使用说明

## OCR 识别方式

管理员在“我的 -> 运行与识别”中为新处理批次选择识别方式。升级后默认仍为本地 OCR，不会因为安装新版本而自动把既有或新上传的健康数据发送到外部服务。

| 方式 | 凭据 | 数据处理位置 | 官方单源文件限额 |
| --- | --- | --- | --- |
| 本地 OCR | 无 | 页面和文字识别都在当前设备 | 不受 MinerU 限额影响 |
| MinerU Agent 轻量解析 | 无 | 页面预处理在本地，完整页面副本发送至 MinerU | 10 MB、20 页 |
| MinerU 精准解析 | 管理员配置 MinerU API Token | 页面预处理在本地，完整页面副本发送至 MinerU，固定使用 `vlm` | 200 MB、200 页 |

全局设置只影响之后新建的上传、NAS 导入、重新识别或页面调整批次。每个批次在创建时固定识别方式，设置变更不会切换已经入队的任务；PDF 拆出的后续页面和自动重试继续继承原批次方式。历史任务没有识别方式记录时一律按本地 OCR 处理。

### MinerU 外部处理确认

MinerU 模式会发送处理后的完整页面副本，页面可能包含姓名、证件号、检查结果等全部健康信息。这里发送的是图像页面，不适用后续 AI 文本输入的字段过滤规则。浏览器上传、NAS 导入、重新识别、旋转、重排和删除页面产生的新批次都必须由当前用户明确确认；重试同一个已创建任务不重复确认。客户端显示的方式与管理员当前设置不一致时，服务端会拒绝创建批次，要求刷新后重新确认。

应用不会发送原始文件名或本地路径。目标页面先由本地 Worker 按旋转方向生成最长边不超过 2400px、质量 95 的临时 JPEG，再提交到固定的 `https://mineru.net`。签名上传地址和结果下载地址不会保存，临时 JPEG 在成功、失败或取消后删除，启动时也会清理超期孤儿文件。

精准解析 Token 使用 AES-256-GCM 加密保存在应用数据目录，接口只显示是否已配置和掩码。Token 只发送到 MinerU 精准解析控制接口；签名文件上传、Agent 接口和结果下载都不会携带 Token。应用不支持自定义 MinerU API 地址，保存设置时也不会发起在线测试或消耗额度。

### 限额、重试和结果

应用按上传前的源文件大小和页数执行官方限额预检。Agent 超过 10 MB/20 页、精准解析超过 200 MB/200 页时，该源文件使用本地 OCR；MinerU 明确返回同类大小或页数错误时也会本地降级。认证失败、网络错误、30 分钟超时、429、服务异常或结果损坏不会静默降级，而是显示 `MINERU_*` 错误并沿用任务的三次重试与诊断流程。

远程任务每 5 秒轮询一次，单页从首次提交起最多等待 30 分钟。进程重启或自动重试会优先使用已保存的 task/batch ID 继续轮询，避免重复上传；签名 URL、Markdown 正文和结果 ZIP 不写入任务事件、日志或审计。

MinerU Markdown 会转换为现有页级 OCR 行，标题、正文和表格单元格继续进入全文搜索、质量评分、AI 规划和证据校验。MinerU Markdown 不提供当前应用兼容的行坐标，因此文字校对和证据引用仍可使用，但原图不会显示伪造的文字叠加位置，界面会提示“当前结果无可用定位坐标”。

## 本地 OCR 环境

进入“我的 -> 运行与识别”安装 OCR 环境。环境保存在应用数据目录，升级或重建容器后会继续使用。PDF 拆页、旋转、缩略图和 MinerU 页面预处理都依赖本地 Worker，因此选择远程模式也需要可用的本地 OCR 环境。PDF 使用本地模式时会按页面处理；文字层不完整时，会结合高清渲染图片再次识别。

OCR 失败不会删除已保存的原件。修复环境后可在报告详情中重试 OCR，或重新执行 OCR+AI。

## AI 配置

AI Provider 在“我的 -> AI 配置”中设置。支持 OpenAI-compatible Provider 和 Ollama，可按场景选择模型。视觉模型只应配置支持图片输入的模型，普通文本模型不能用于视觉任务。

AI 结果会经过本地证据校验。无法回指 OCR 原文、单位不明确或来源存在冲突的结果不会默认进入趋势，但仍可在报告中查看和人工校对。

## 数据边界

发送 AI 前会过滤姓名、证件号、电话、地址、邮箱和精确出生日期等直接身份信息。该过滤只针对 AI 文本输入，不会处理发送给 MinerU 的完整页面图像。原件、MinerU 页面副本、OCR 正文、报告结果和 AI 配置都属于敏感数据，应分别根据 MinerU 和所选 AI Provider 的隐私政策决定是否启用。

## 指标字典

核心和远程字典负责标准名称、别名、分类、指标类型和单位兼容规则。未命中的定量/定性项目进入管理员问题池，不会由 AI 自动创建标准指标。维护者确认后发布远程字典，管理员可检查更新并在本地回填历史指标。

形态发现、器官描述、查体部位、科室小结和报告叙事不属于趋势指标，不应为了减少未命中数量而加入指标字典。详细规则见[指标字典说明](../dictionary/README.md)。
